# 위키드스톰 홈페이지

위키드스톰 공식 홈페이지 **https://wickedstorm.kr** 의 원본 저장소입니다. 2026년 9월 28일에 공개했습니다.

이 문서는 개발자가 아닌 분을 위한 요약입니다. 개발 · 점검 · 배포 방법은 [`DEVELOPER.md`](DEVELOPER.md)에 있습니다.

## 사이트 구성

- **홈**: 여섯 장면으로 된 스크롤 이야기(학습데이터 수집 → AI 분석 → 교수자의 판단 → 다음 학기) 뒤에 제품 · 표준 · 레퍼런스 · 소식 · 회사 · 문의 · 자료 받기가 이어집니다.
- **메뉴**: 에듀테크 · 뉴스룸 · 회사소개 · 도입 문의. 모바일 메뉴에는 신뢰(인증 · 특허 원본) · 채용이, 푸터에는 신뢰 · 자료 받기 · 채용 · 개인정보처리방침이 더 있습니다.
- **네 언어**: 한국어 · English · 日本語 · Tiếng Việt. 소식도 네 언어로 나옵니다. 방문자를 다른 언어 페이지로 자동으로 보내지 않고, 안내 띠만 띄웁니다.
- **링크 모음**(`/links.html`): 인스타그램 프로필에 거는 한 화면짜리 페이지입니다.
- **숨긴 페이지**: 제품 · 사례 페이지는 메뉴와 검색에서 빼 두었습니다. 주소는 남아 있습니다.

## 문의가 들어오면

1. 방문자가 문의 양식을 보내면 서버가 바로 접수합니다.
2. 문의는 **문의 관리표**(구글 시트)에 한 줄로 기록되고, **manager@wickedstorm.kr**로 알림 메일이 갑니다(담당자 참조).
3. 메일 제목과 본문 끝 '접수 정보'에 문의 목적, 들어온 경로(광고 · 검색 · 인스타그램 등), 접속 국가, 접수 번호가 붙습니다.
4. 관리표 기록이 계속 실패하면 알림 메일에 "관리표 자동 저장을 확인하지 못했습니다"가 붙습니다. 메일 발송까지 계속 실패하면 manager@로 경고 메일이 옵니다.

- 시험 문의는 이메일 `homepage-test@example.com`, 본문에 `CONTACT-QA-`를 넣어 보냅니다. 관리표에서 시험 행으로 구분됩니다.
- 개인정보처리방침에 따라 문의 기록은 **1년** 보관한 뒤 파기합니다. 관리표는 자동으로 지워지지 않으니 1년이 지난 행은 직접 지웁니다(첫 대상: 2027년 9월).

## 방문 통계

- Google Analytics 4(GA4)로 방문과 문의를 봅니다. 문의 양식을 쓰기 시작하면 `contact_start`, 보내면 `generate_lead`가 남습니다.
- 이름 · 이메일 · 소속 · 문의 내용은 GA4로 보내지 않습니다.
- 회사 사무실에서의 방문은 통계에서 빠집니다. 사무실에서 시험 문의를 보내면 GA4 실시간 보고서에 보이지 않으니, 휴대폰 데이터로 확인합니다.
- 광고 · 캠페인 링크(UTM) 만드는 법과 보고서 보는 법: [`docs/marketing/analytics.md`](docs/marketing/analytics.md)

## 내용을 바꾸고 싶을 때

관리 화면은 없습니다. 문구와 소식은 이 저장소의 파일로 관리하고, 개발 담당이 고칩니다. 요청할 때 아래를 알려 주세요.

- **어디를**: 페이지 주소나 화면 캡처, 언어
- **어떻게**: 지금 문구와 바꿀 문구. 국문만 주셔도 나머지 언어는 번역해 넣습니다.
- **소식 글**: 제목, 날짜, 요약, 본문, 사진(사용 허락을 받은 것), 바깥 기사라면 그 주소

반영 순서:

1. 개발 담당이 고쳐서 변경 요청(PR)을 올립니다.
2. 자동 점검이 네 언어 · 화면 폭 9가지에서 화면 깨짐, 접근성, 속도, 깨진 링크를 확인하고 결과표를 PR에 남깁니다.
3. 검토 뒤 병합하면 미리보기 주소가 바뀝니다.
4. **운영 사이트는 배포 명령을 실행해야 바뀝니다.** 병합만으로는 운영에 나가지 않습니다.

## 문구 원칙

- 인증 · 특허 · 실적은 원본으로 확인할 수 있는 것만 쓰고, 원본 링크를 둡니다.
- 제품명은 **Lecognizer, Lecognizer AI, LearnHubble AI**입니다. GROWA · LXP는 제품명처럼 쓰지 않습니다.
- 제품 화면 속 숫자는 시연용이라 성과처럼 쓰지 않습니다. "누적 사용자 240만 명"은 사업명(똑똑! 수학탐험대)과 함께 레퍼런스에서만 씁니다.
- AI는 찾고 분석하고 제안하며, 판단과 적용은 사람이 한다는 관점으로 씁니다.
- 긴 줄표(—)와 "(개발 중)" 표기는 쓰지 않습니다.
