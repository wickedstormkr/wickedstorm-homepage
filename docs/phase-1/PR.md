# 1단계: 기반 만들기 (Astro 뼈대 · 디자인 토큰 · 네 언어 · 자동 점검 · 지금 사이트 내용 이전)

`docs/tasks/phase-1.md`를 수행했습니다. `npm run build`로 정적 사이트가 나오고, 지금 사이트(homepage_renewal)의 모든 섹션·문구·네 언어·소식 목록과 상세·개인정보처리방침·링크 페이지가 새 구조로 뜹니다. 404는 새로 만들었습니다. 히어로는 정적인 기본 층(제목, 리드, 버튼, 증빙 한 줄)만 두었고, 여섯 장면 연출은 2단계입니다.

## 구조
- **빌드**
  - Astro 7.3.5(정적 출력), TypeScript strict(`astro check` 오류 0).
  - `build.format: 'preserve'`로 지금 사이트 주소를 그대로 지킵니다: `/`, `/en/index.html`, `/ja/index.html`, `/vi/index.html`, `/news.html`, `/news/<id>.html`, `/privacy.html`, `/links.html`. 인쇄된 QR과 공유된 기사 주소가 도메인 전환 뒤에도 이어집니다.
- **site·base**: `site.config.mjs` 한 곳에서 바꾸고, 환경 변수 `SITE_URL`·`BASE_PATH`로 덮어쓸 수 있습니다. 사이트 안 주소는 모두 `src/lib/url.ts`를 거칩니다. `BASE_PATH=/wickedstorm-homepage/`(GitHub Pages 가정)로 빌드해 링크·axe·동작 점검이 통과하는 것도 확인했습니다.
- **콘텐츠 파일**
  - 홈: `src/content/home/<lang>/<section>.json`. 언어마다 11개 파일: common, hero, pipeline, product, learnhubble, references, standards, news, resources, company, contact.
  - 화면 부품 문구: `src/content/ui/<lang>.json`.
  - 소식: `src/content/posts/posts.json`. 관리 화면과 같은 형식이고, 콘텐츠 컬렉션과 zod 스키마로 읽습니다.
- **토큰**: `src/styles/tokens.css` 한 파일에 모았습니다.
  - 배경·패널·글자·선, 브랜드 그라디언트 `--grad`, 제품 조각 `--grad-lec`·`--grad-lhb`, `--accent`
  - 글꼴, 크기(본문 15px·최소 11px), 누르는 곳 44px, 레이아웃
- **언어**
  - hreflang(ko·en·ja·vi·x-default)과 canonical을 넣었습니다.
  - 언어 선택은 원어 이름(한국어 · English · 日本語 · Tiếng Việt)으로 씁니다.
  - 자동 이동은 없습니다. 브라우저 첫 언어가 다르면 그 언어로 안내 띠만 띄웁니다.
  - 줄바꿈: 한국어 keep-all, 일본어 글자 단위 + `line-break:strict`, 제목은 빌드 때 BudouX, 베트남어는 줄간격을 넓혔습니다.
- **움직임 멈춤**: 오른쪽 위 버튼이 반복 애니메이션을 모두 멈춥니다(KWCAG 6.2.2). 선택을 기억하고, reduced-motion이면 멈춘 상태로 시작합니다. 2단계 연출이 따를 API는 `src/scripts/motion.ts`입니다.
- **첫 로드 JS**: 4.1KB(gzip). GSAP·Lenis·WebGL은 2단계에서 불러옵니다.
- **폴더 전체 설명**: README '구조'.
